Container containerCreateStack(size_t size, size_t elementSize, [[deprecated]] bool elementsArePointers)

Container* containerCreateHeap(size_t size, size_t elementSize, [[deprecated]] bool elementsArePointers)

Both functions create a Container and allocate specified memory. containerCreateHeap allocates the structure on the heap while containerCreateStack returns the structure on the stack. Returns value should be checked with isValidObject. containerCreateHeap can additionally be checked if it is null or not.

Functions will fail if memory for structure or array cannot be allocated. containerCreateStack with size = 0 will never fail.

  • size is specifying the amount of elements the container is able to contain.
  • elementSize is specifying the size of a individual element in the Container. This is only a maximum limit. Smallar elements may be inserted
  • elementsArePointers is a deprecated parameter which shall always be false.
