BL_Container bl_container_create_stack(size_t size, size_t elementSize)

BL_Container* bl_container_create_heap(size_t size, size_t elementSize)

Both functions create a Container and allocate specified memory. container_create_heap allocates the structure on the heap while bl_container_create_stack returns the structure on the stack. Returns value should be checked with container_is_valid. container_create_heap can additionally be checked if it is null or not.

Functions will fail if memory for structure or array cannot be allocated. bl_container_create_stack with size = 0 will never fail.

  • size is specifying the amount of elements the container is able to contain.
  • elementSize is specifying the size of a individual element in the Container. This is only a maximum limit. Smallar elements may be inserted
